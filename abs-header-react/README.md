# iABS Header — React + TypeScript

    npm install
    npm run dev

- src/components/Header.tsx  : الواجهة والتفاعل (حالات، تمرير، لغة، قائمة الجوال)
- src/components/frame.ts    : حساب مسارات إطار الـ SVG (قصّات، جيب، علامات، تقدّم)
- src/components/data.tsx    : الروابط والأيقونات والترجمة
- src/styles/header.css      : كل الألوان والحركات والانتقالات

للدمج في موقعك: انسخ components + styles + assets/logo.png واستخدم <Header />.
ids الأقسام (social, stream, support, schedule, archive) لازم تطابق صفحتك.
